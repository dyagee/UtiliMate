# UtiliMate – Ultimate Utility Toolbox 🧰📱

**UtiliMate** is an all-in-one utility mobile app built with Flutter.  
It combines **powerful productivity tools** (like PDF and image utilities) with **everyday life helpers** (like converters, calculators, and generators) into a single, modern, easy-to-use app.

---

## ✨ Features

### 📄 PDF & Document Tools
- Convert **Image → PDF**
- Merge multiple PDFs
- Split PDFs (by range or individual pages)
- Compress PDFs

### 🖼️ Image Tools
- Resize images
- Crop images
- Convert image formats (JPG, PNG, etc.)
- Extract text from images (OCR)

### 🔤 Text & Generators
- Password generator (strong, customizable)
- Text manipulation & find/replace
- Fake address & name generators
- Random number generator & picker
- Random text generator (multi-language, paragraphs)

### 🧮 Converters & Calculators
- Unit converter
- Currency converter
- Age calculator
- Discount calculator
- BMI calculator

### 📲 Other Handy Tools
- QR code generator & scanner
- Stopwatch & timer
- Color picker
- Universal video downloader ⚡

---

## 📂 File Manager
- Integrated **Files tab** to view, rename, delete, or share all files generated by UtiliMate.

---

## 🖌️ UI & UX
- Clean **Material 3 design**
- Light/Dark theme support
- Distinguishes between **online** and **offline** tools.
- Smooth navigation via **bottom navigation bar**:
  - 🏠 Home – all tools at a glance  
  - 📂 Categories – grouped by type  
  - 📑 Files – file browser & manager  
  - ⚙️ Settings – preferences and controls
